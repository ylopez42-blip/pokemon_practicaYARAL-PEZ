# Pokédex

Explora Pokémon, consulta sus datos y descubre sus líneas evolutivas. La
interfaz se adapta a celulares, tabletas y computadoras.

**Abrir la aplicación web:** https://ylopez42-blip.github.io/pokemon_practicaYARAL-PEZ/site/

## Ejecutar localmente

```bash
flutter pub get
flutter run -d chrome
```
